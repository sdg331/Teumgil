# 틈길 결승 시연 시나리오

> 가상 데이터로 시연하기 위한 초안 · 2026-10-29. 기획 원문에 기록된 조건은 영상 7분 이내, 2026-11-13 제출입니다. 실제 촬영 전 주최 측의 최신 안내를 확인합니다.

## 시연에서 보여 줄 한 가지

시민이 시장을 이용하다 불편을 선택적으로 알리고, 운영자가 확인한 뒤 관련 상인의 입장과 대안을 듣고, 시민에게 확인된 결과 또는 미해결 사유를 전하는 과정.

시장·점포·사람·의견은 가상입니다. 실제 협력이나 현장 개선 효과를 보여 주는 사례가 아닙니다.

## 시연에 필요한 가상 자료

| 자료 | 준비할 내용 | 아직 정해야 할 점 |
| --- | --- | --- |
| 시장·점포 | 가상 시장 1곳과 대파를 평소 취급하는 가상 점포 | 시장명, 점포명, 위치, 확인일 |
| 장보기 | 처음에는 빈 목록 | 시연 시작 전 초기화 방식 |
| 의견 | 시장 입구에 상자가 있어 유모차 통행이 어려웠다는 가상 입력 | 위치의 상세 설명 |
| 관련 상인 | 운영자가 관련성을 확인했다는 설정의 가상 상인 | 어떤 근거로 관련성을 확인했는지 시연용 설정 |
| 상인 답변 | 입장과 가능한 대안 또는 대안이 없다는 답변 | 구체 문구 |
| 처리 결과 | 실제 확인한 조치 또는 확인 불가 사유를 기록하는 가상 결과 | 어떤 결과를 보여 줄지, 후속 확인 계획 |

가상 상인과 물건의 관계를 자동으로 단정하지 않습니다. 실제 점포나 사람을 연상시키는 자료를 쓰려면 사용 여부를 별도로 확인합니다.

## 화면 순서와 발표 메모

시간은 연습 전 배분안입니다. 세부 발표 원고가 아니라 화면에서 무엇을 보여 주고 어떤 뜻을 전달할지에 집중합니다.

| 시간 | 화면과 행동 | 전달할 내용 |
| --- | --- | --- |
| 0:00–0:45 | 프로젝트 소개 | 보행·영업 공간에서 생기는 불편을 확인과 협의로 연결하는 틈길 소개 |
| 0:45–1:35 | 가상 시장에서 대파 검색 → 점포 확인 → 장바구니 추가 | 평소 시장 이용 흐름. 취급 품목과 당일 재고·가격의 차이 |
| 1:35–2:35 | 시장 입구 선택 → 상황 입력 → 원문과 초안 비교 | 불편 알리기는 선택 사항. 시점은 모르면 비우고 사진은 선택 |
| 2:35–3:15 | 틈길에 알리기 → 접수 확인 | 틈길 내부 접수이며 공식 신고는 별도 창구에서 이용 |
| 3:15–4:25 | 운영자 역할로 확인 → 필요한 내용을 상인에게 전달 → 상인 역할로 답변 | 역할 전환은 데모. 관계 확인 후 필요한 내용만 전달 |
| 4:25–5:20 | 운영자가 결과·사유 기록 → 시민 역할의 마이에서 확인 | 확인된 사실과 미해결을 구분. 후속 확인이 계획이라면 계획이라고 설명 |
| 5:20–6:15 | 검증할 과제 설명 | 실제 상인 참여, 운영 주체, 현장 효과는 검증 전 |
| 6:15–6:45 | 마무리 | 일상 이용과 확인·협의를 연결하는 흐름 정리 |

계획상 6분 45초이며 실제 녹화 길이는 연습으로 확인해야 합니다. 설명이 길어지면 구현하지 않은 기능 소개보다 핵심 흐름을 먼저 보여 줍니다.

## 실행 순서

1. 시연 데이터를 초기화하고 시민 데모 역할로 시작합니다.
2. 가상 시장에서 대파 취급 점포를 찾습니다. 확인되지 않은 당일 재고·가격은 미확인으로 표시합니다.
3. 대파를 목록에 추가하고 시장지도에서 가상 입구를 선택합니다.
4. 상황 원문을 입력하고 초안을 비교·수정합니다. 템플릿을 썼다면 템플릿이라고 설명합니다.
5. 내부 의견을 제출하고 운영자 역할로 바꾸어 같은 의견을 확인합니다.
6. 관련성이 확인된 가상 상인에게 필요한 내용을 전달하고, 상인 역할에서 준비된 답변을 입력합니다.
7. 운영자가 조치 또는 미해결 사유를 기록합니다. 시민 역할의 마이에서 같은 의견의 이력을 보여 줍니다.

구체 화면 동작은 [제품·화면 명세](PRODUCT_SCREENS.md)를 따릅니다. 아직 구현되지 않은 단계는 시안으로 설명할 수 있지만 동작하는 것처럼 시연하지 않습니다.

## 리허설에서 확인할 것

- [ ] 시작 상태로 되돌린 뒤 같은 흐름을 두 번 재현할 수 있다.
- [ ] 역할 전환과 새로고침 뒤 결과가 선택한 저장 방식의 설명과 일치한다.
- [ ] 화면에 가상 자료, 데모 역할, 템플릿 사용 여부가 드러난다.
- [ ] 공식 신고 안내와 긴급 위험 안내를 보여 줄 수 있다.
- [ ] 화면의 글자·커서와 녹음된 설명이 잘 보이고 들린다.
- [ ] 녹화 시간을 실측해 제한 이내인지 확인했다.
- [ ] 시연 실패 시 실제 구현 범위와 준비된 대체 화면을 구분해 설명할 수 있다.
