# 장보기 상세 명세 · S04

[제품 기준](../PRODUCT_SCREENS.md)의 R1·R3·R8, [공통 기준](COMMON.md)을 적용한다. 장바구니는 살 재료를 정리하는 목록이며 주문·결제 화면이 아니다.

## S04 장바구니

| 항목 | 명세 |
| --- | --- |
| 목적 | 메뉴 선택 없이 재료를 직접 적고, 체크·수정·삭제하거나 관련 점포를 찾는다 |
| 진입 | 장바구니 탭, 홈 이어보기, S03에서 목록 보기 |
| 읽는 자료 | 본인/데모 주체의 목록 ID와 항목 ID·재료명·체크 상태, 선택 시장 |
| 쓰는 자료 | 항목 추가·이름 수정·체크·삭제 |
| 이동 | 관련 점포 찾기 → S02에 시장·품목 전달, 점포 선택 → S03 |
| 결정 필요 | D1 저장·복구, D2 중복·수량·목록의 시장 범위, D7 실제 소유자 확인 |

### 영역

| 영역 | 표시 정보 | 조건 |
| --- | --- | --- |
| 제목·목록 맥락 | 장바구니, 현재 목록·시장 맥락 | 선택 시장이 없으면 점포 찾기 전에 시장 선택 안내 |
| 재료 입력 | 보이는 이름표·재료명·추가 행동 | 공백만 입력한 항목은 저장하지 않음 |
| 항목 목록 | 항목별 체크·재료명·수정·삭제·관련 점포 찾기 | 행 전체와 개별 버튼의 동작이 충돌하지 않도록 영역 구분 |
| 비어 있음 | 아직 담은 재료가 없다는 안내 | 정상적으로 빈 목록을 읽었을 때만 표시 |
| 저장 범위 안내 | 해당 기기·세션·계정에서 유지되는 범위 | D1의 실제 동작과 일치. 자동 동기화가 없으면 약속하지 않음 |

냉장고 재료·메뉴 추천·배송·구매 합계·예상 가격은 핵심 목록에 자동 추가하지 않는다. 수량·정렬·완료 항목 묶음은 D2와 화면 검토에서 정한다.

## 입력·변경 계약

| 항목 | 입력·검증 | 결과 |
| --- | --- | --- |
| 재료명 | 사람이 입력한 텍스트. 공백만 있는 값 거부 | 저장 후 식별 가능한 항목 생성 |
| 체크 | 해당 항목의 현재 완료 여부 | 명시적으로 선택한 상태로 변경. 실제 구매·방문 성공을 추정하지 않음 |
| 이름 수정 | 대상 항목 ID·새 재료명. 공백만 있는 값 거부 | 같은 항목의 이름 변경. 체크 상태의 유지·초기화 정책은 D2에서 확정 |
| 삭제 | 대상 항목 ID | 해당 항목만 제거. 다른 항목·계정·목록 변경 금지 |
| 관련 점포 | 재료명·선택 시장 | 해당 조건의 S02 결과. 재고 보장은 아님 |

재료명의 저장 표현과 중복 비교용 정규화를 구분한다. 중복을 자동 합치거나 수량을 증가시키는 규칙은 아직 정하지 않았다.

## 동작 순서

### 재료 추가

1. 입력창에 재료를 적고 추가 버튼 또는 Enter를 선택한다.
2. 입력 검증 후 대상 목록에 저장한다. D2에서 정한 중복 정책을 적용한다.
3. 저장 성공 후 새 항목과 피드백을 표시하고 다음 재료 입력을 이어갈 수 있게 한다.
4. 실패하면 입력 문구를 유지한다. 이미 저장됐는지 모르는 경우에는 C3의 결과 미확인 처리를 따른다.

### 체크·수정·삭제

- 체크의 화면 상태와 실제 저장 결과가 달라지면 사용자에게 알리고 일치시킨다. 저장 도중 같은 항목을 연속 변경할 때 마지막 의도가 반영되는지 검증한다.
- 수정은 항목 이름 옆의 조작으로 진입한다. 저장하면 같은 항목 ID에 반영하고 취소하면 원래 이름을 유지한다.
- 삭제는 대상을 식별할 수 있게 한다. 되돌리기 또는 확인 방식은 실제 복구 가능성과 화면 설계에 맞춰 선택한다.
- 마지막 항목 삭제 성공 후에만 빈 목록 화면으로 바꾼다. 요청 실패를 삭제 완료로 표시하지 않는다.

### 관련 점포 찾기

1. 재료와 선택 시장을 S02에 전달한다.
2. 시장이 없으면 시장을 고르게 하고 기존 재료를 유지한다.
3. 결과는 평소 취급 품목과의 일치다. 실제 재고·가격이 있다는 뜻으로 설명하지 않는다.
4. 돌아오면 기존 목록과 체크 상태를 유지한다. 시장을 바꿨을 때 목록을 공유할지 분리할지는 D2에서 결정한다.

## 예외별 처리

| 상황 | 처리와 복구 |
| --- | --- |
| 처음 이용·빈 목록 | 재료를 직접 입력할 경로. 메뉴·의견 작성 강제 없음 |
| 목록 읽기 실패 | 오류·재시도. 읽지 못한 목록을 빈 목록으로 덮어쓰지 않음 |
| 공백 재료 | 해당 입력 오류. 기존 항목은 변경하지 않음 |
| 저장 용량·연결 문제 | 실패 범위와 재시도. 실제 저장 범위와 복구 한계를 안내 |
| 항목이 이미 변경·삭제됨 | 최신 자료를 다시 확인하고 적용 대상이 없어졌음을 안내. 다른 항목에 조작하지 않음 |
| 관련 점포 없음 | 결과 없음. 임의 점포·품목·가격을 생성하지 않음 |
| 역할·계정 변경 | 다른 주체의 목록을 섞지 않음. 데모라면 주체와 초기화 정책을 표시 |
