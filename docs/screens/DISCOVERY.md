# 시장 탐색 상세 명세 · S01–S03

[제품 기준](../PRODUCT_SCREENS.md)과 [화면 공통 기준](COMMON.md)을 함께 적용한다. 화면 영역 순서는 정보 구조 제안이며 픽셀 단위 디자인이나 확정 URL이 아니다.

## S01 홈

| 항목 | 명세 |
| --- | --- |
| 목적 | 이용할 시장을 찾거나 기존 장보기를 이어간다 |
| 진입 | 앱 시작, 홈 탭 |
| 대상 | 시민 탐색. 상인·운영자도 일반 탐색 화면을 사용할 수 있음 |
| 읽는 자료 | 검색 가능한 시장, 현재 선택 시장, 인증된 본인의 장보기 요약, 게시된 공지 |
| 주요 이동 | 시장 선택 → S02, 장보기 이어보기 → S04 |
| 적용 기준 | D1 유지 범위, D7 본인 식별. 공지 상세·AI 메뉴 추천은 이 명세의 핵심 범위 밖 |

### 영역과 표시 조건

| 영역 | 표시할 정보 | 조건·행동 |
| --- | --- | --- |
| 상단 | 틈길 이름, 필요한 가상 데이터 안내 | 꾸며낸 이용자 수·성과 수치를 표시하지 않음 |
| 시장 검색 | 보이는 이름표, 검색어, 검색 실행·지우기 | 빈 검색어는 시장 둘러보기와 구분 |
| 시장 결과 | 이름, 확인 가능한 위치 설명, 가상 여부 | 선택하면 시장 ID를 S02에 전달 |
| 장보기 이어보기 | 저장된 목록의 실제 요약 | 목록이 있으면 이어보기, 없으면 목록 시작 안내 |
| 공지 | 게시 자료의 제목·게시 시점 | 자료가 없으면 추천·공지로 임의 채우지 않음 |
| 하단 탭 | 홈·시장지도·장바구니·마이 | 홈의 현재 위치를 표시 |

### 상호작용

1. 검색 입력값과 마지막으로 실행한 검색어를 구분한다. 검색 버튼·Enter로 실행하는 안을 사용한다.
2. 검색 실행 후 읽기 중→결과 또는 결과 없음·실패를 표시한다. 다른 검색어의 늦은 응답이 최신 결과를 덮지 않게 한다.
3. 결과의 시장을 선택하면 S02의 시장 맥락을 바꾼다. 기존 장보기 목록을 자동 삭제하지 않는다.
4. 장보기 이동은 실제 유지된 목록을 연다. 복구 자료가 없으면 복구된 것처럼 표시하지 않는다.

| --- | --- | --- |
| S01-T1 | 가상 시장이 있는 검색어 실행 후 시장 선택 | 선택 시장 ID로 S02 진입, 가상 표시 유지 |
| S01-T2 | 일치하지 않는 검색어 실행 | 결과 없음과 검색 수정 경로. 로딩·실패와 구분 |
| S01-T3 | 기존 장보기 목록이 있는 상태에서 시장 변경 | 목록이 삭제되지 않음. 시장 범위 규칙은 D2와 일치 |

## S02 시장지도·점포 목록

| 항목 | 명세 |
| --- | --- |
| 목적 | 현재 시장의 점포·평소 취급 품목을 찾고, 필요한 경우 의견 위치를 고른다 |
| 진입 | 시장지도 탭, S01 시장 선택, S04 관련 점포 찾기 |
| 들어오는 맥락 | 선택 시장 ID, 선택적 품목 검색어, 돌아갈 화면 |
| 읽는 자료 | 현재 시장·점포·평소 취급 품목, 도식/지도 위치 |
| 주요 이동 | 점포 선택 → S03, 위치를 선택하고 알리기 → S05 |
| 쓰기 | 화면 선택 맥락. 시장 탐색만으로 의견을 생성하지 않음 |

### 영역과 데이터

| 영역 | 정보 | 조작·표시 규칙 |
| --- | --- | --- |
| 현재 시장 | 시장명·위치 설명·가상 여부 | 시장 미선택 시 선택 경로. 현재 위치를 무단으로 추정하지 않음 |
| 검색 | 점포명 또는 품목 | S04에서 품목이 전달되면 적용된 검색어로 표시 |
| 결과 정보 | 현재 조건과 실제 결과 | 새 검색이 끝나기 전 결과를 최신으로 표현하지 않음 |
| 지도·도식 | 점포 위치와 선택한 점포/의견 위치 | 도식이면 가상 도식 표시. 지도 없거나 실패해도 목록 탐색 경로 유지 |
| 점포 목록 | 점포명·위치·평소 품목·출처·확인일 | 재고/가격은 확인 자료가 있을 때만. 자료 부재 시 미확인 |
| 선택 정보 | 선택 점포 또는 의견 위치 설명 | 점포 선택과 제보 위치 선택을 구별 |
| 알리기 | 현재 의견 위치와 함께 진입 가능한 행동 | 의견 작성은 탐색의 필수 단계가 아님 |

### 상호작용

- **검색:** 현재 시장 안에서 점포명·품목을 찾는 안이다. 다른 시장까지 자동 확장한다면 별도 범위로 표시한다.
- **점포 선택:** 목록과 지도에서 같은 점포 ID를 선택한다. 선택 점포가 보이는 정보와 일치해야 한다.
- **의견 위치 선택:** 특정 지점을 선택하거나 S05에서 설명하도록 한다. 좌표·도식 지점과 사람이 쓴 설명을 구별한다.
- **알리기:** 시장 ID, 알고 있는 위치 설명·지점을 S05로 전달한다. 가까운 점포를 물건의 소유자로 자동 지정하지 않는다.
- **복귀:** S03 또는 S05에서 돌아오면 기존 검색어·시장·선택을 보존하는 안이다. 새로고침 후 유지 범위는 D1을 따른다.
- **시장 변경:** 새 시장의 점포·위치 맥락을 다시 읽는다. 이전 시장의 선택 지점을 새 시장 위치로 재사용하지 않는다.

카테고리 필터를 넣는다면 실제 점포 자료에 존재하는 분류만 쓴다. 인기·안전 등급이나 영업 중 필터는 확인 데이터 없이 추가하지 않는다.

### 예외

| 상황 | 처리 |
| --- | --- |
| 점포 검색 결과 없음 | 현재 시장·검색어와 결과 없음을 표시. 검색어 지우기 또는 시장 변경 |
| 지도만 실패 | 목록이 있으면 목록을 계속 사용. 위치 선택은 설명 입력으로 대체 가능 |
| 점포 위치 없음 | 위치 미확인을 표시. 지도에 임의 핀을 만들지 않음 |
| 점포 자료 읽기 실패 | 점포 결과 실패와 재시도. 실패를 결과 0개로 표시하지 않음 |
| 다른 시장의 점포 ID | 시장 맥락을 확인해 올바르게 이동하거나 대상 불일치 안내. 섞어서 표시하지 않음 |

## S03 점포 상세

| 항목 | 명세 |
| --- | --- |
| 목적 | 점포가 평소 무엇을 취급하는지 확인하고 장보기와 연결한다 |
| 진입 | S02 점포 선택, S04 관련 점포 선택 |
| 필수 맥락 | 점포 ID와 시장 맥락 |
| 읽는 자료 | 해당 점포·품목·출처·확인일, 허용된 소개·사진 |
| 주요 행동 | 선택 품목을 장보기 목록에 추가, 이전 탐색으로 돌아가기 |
| 적용 기준 | D2 중복·시장 범위, 사진·실제 점포 게시 자료의 사용 조건 |

### 구성과 표시

1. **점포 기본 정보:** 점포명, 시장, 위치 설명. 없으면 미확인으로 표시한다.
2. **평소 취급 품목:** 각 품목과 출처·확인일. 당일 판매·재고 보장으로 바꾸지 않는다.
3. **재고·가격:** 확인 자료가 없으면 각각 미확인. 평소 품목으로 가격을 생성하지 않는다.
4. **점포 소개·이미지:** 허용된 자료가 있을 때만 표시한다. 이미지가 없어도 핵심 텍스트를 읽을 수 있어야 한다.
5. **품목별 장보기 행동:** 어떤 재료를 추가하는지 분명히 표시한다. 관련 점포가 없는 사용자 재료도 S04에서 직접 추가할 수 있다.

### 행동과 결과

| 행동 | 저장/이동 결과 | 실패·주의 |
| --- | --- | --- |
| 품목 추가 | 인증된 본인 목록에 항목 추가, 결과 확인 후 피드백 | D2의 중복 처리 적용. 요청 중 반복 클릭 방지 |
| 목록 보기 | S04에서 같은 목록 열기 | 점포 방문·구매 완료로 기록하지 않음 |
| 돌아가기 | 들어온 S02 또는 S04로 복귀 | 시장·검색어·선택 맥락 유지 |
| 점포 정보 없음 | 내용 없음과 목록으로 돌아가기 | 다른 점포 자료를 대신 표시하지 않음 |

즐겨찾기·홍보·연락·수정 요청 버튼은 별도 범위가 정해졌을 때 추가한다. 버튼 공간을 채우기 위해 기능을 약속하지 않는다.
