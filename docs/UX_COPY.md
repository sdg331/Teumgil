# 틈길 화면 문구 기준

> 화면 구현을 위한 문구 초안 · 2026-10-29. 버튼 이름과 안내 문구는 실제 화면·사용자 검토에 따라 바뀔 수 있습니다. 화면 동작과 입력 조건은 [제품·화면 명세](PRODUCT_SCREENS.md)를 기준으로 합니다.

## 문구를 쓸 때

이용자가 지금 할 일과 이미 확인된 사실부터 말합니다. 존댓말을 쓰되 상황을 가볍게 여기지 않고, 책임이나 결과를 대신 판단하지 않습니다. 버튼에는 다음 행동을 적고, 오류에는 가능한 다음 행동을 함께 안내합니다.

## 용어

| 화면의 말 | 의미와 사용 위치 | 사용하지 않을 말 |
| --- | --- | --- |
| 틈길에 알리기 | 틈길 내부에 의견을 보내는 버튼 | 공식 민원 자동 접수 |
| 공식 신고 창구 이용하기 | 이용자가 외부 창구에서 직접 신고하는 경로 | 틈길에서 공식 신고 완료 |
| 평소 취급 품목 | 출처와 확인일이 있는 점포 정보 | 확인 없이 오늘 재고 있음 |
| 장바구니 | 살 재료 목록 | 주문·결제·배송을 뜻하는 문구 |
| 확인된 조치 있음 | 무엇을 언제 확인했는지 기록한 상태 | 완전 해결, 안전 확보 |
| 가상 시장 도식 | 시연용 위치 표현 | 실제 지도 또는 실시간 정보 |
| 예시 템플릿으로 정리 | 정해진 규칙으로 만든 초안 | 실제 호출 없이 AI 분석 완료 |

## 화면별 문구

### 시장지도·장보기

| 상황 | 문구 | 행동 |
| --- | --- | --- |
| 검색 | 시장이나 재료를 검색해 주세요. | 검색 |
| 결과 없음 | 검색 결과가 없어요. 다른 이름으로 검색해 보세요. | 검색어 수정 |
| 점포 정보 | 평소 취급 품목 · 출처와 확인일 표시 | 점포 상세 보기 |
| 당일 정보 없음 | 재고 미확인 / 가격 미확인 | — |
| 목록이 비어 있음 | 아직 담은 재료가 없어요. | 재료 추가 |
| 재료 입력 | 살 재료를 입력해 주세요. | 재료 추가 |

### 의견 작성·접수

| 상황 | 문구 | 행동 |
| --- | --- | --- |
| 위치 입력 | 불편을 겪은 위치를 선택하거나 설명해 주세요. | 위치 선택 |
| 상황 입력 | 어떤 불편을 겪었는지 적어 주세요. | 내용 입력 |
| 시점 입력 | 발견한 날짜나 시간을 알고 있다면 적어 주세요. 모르면 비워 두셔도 돼요. | 선택 입력 |
| 사진 | 사진 첨부는 선택 사항이에요. | 사진 첨부 |
| 초안 검토 | 원문과 정리된 내용을 비교하고 필요한 부분을 수정해 주세요. | 내용 수정 |
| 초안 생성 실패 | 내용을 정리하지 못했어요. 직접 작성하거나 다시 시도해 주세요. | 직접 작성 / 다시 시도 |
| 내부 접수 전 | 작성한 내용은 틈길에 전달되며 공식 민원으로 자동 접수되지 않아요. | 틈길에 알리기 / 공식 신고 창구 이용하기 |
| 저장 실패 | 저장하지 못했어요. 입력한 내용을 확인하고 다시 시도해 주세요. | 다시 시도 |
| 접수 성공 | 틈길에 의견이 접수됐어요. 확인 과정은 마이에서 볼 수 있어요. | 내 의견 보기 |

성공 문구는 실제 저장이 성공했을 때만 사용합니다. 입력이 보존되지 않았다면 보존됐다고 안내하지 않습니다.

### 확인과 결과

| 상태 | 문구 예시 |
| --- | --- |
| 추가 정보 필요 | 상황을 확인하기 위해 추가 정보가 필요해요. |
| 협의 중 | 관련 내용을 확인하고 상인의 의견을 듣고 있어요. |
| 확인된 조치 있음 | 확인된 조치가 있어요. 확인 내용과 시각을 살펴보세요. |
| 확인 불가 / 대안 미확보 | 아직 확인하지 못한 내용이 있어요. 확인 내용과 사유를 살펴보세요. |

상태명은 [데이터 계약의 상태 표](DATA_ACCESS.md)와 맞춥니다. 문구에서 조치 확인을 완전 해결이나 공식 처리로 확대하지 않습니다. 앱 AI의 고정 notice는 [출력 규격](prompts/README.md)을 따르며 여기의 UI 문구로 대체하지 않습니다.

## 반드시 구분할 안내

- 공식 신고: “공식 신고를 원하시면 해당 창구에서 요건을 확인하고 직접 제출해 주세요.”
- 긴급 위험: “즉각적인 긴급 위험이 있다면 틈길 처리를 기다리지 말고 119 또는 112에 연락해 주세요.”
- 가상 데이터: “시연을 위해 만든 가상 시장과 점포 정보입니다.” 표시 범위는 실제 자료에 맞춥니다.
- 시연 계정: “가상 자료로 진행하는 시연입니다.” 역할은 각 계정의 서버 권한으로 구분한다.
- 확인일: 확인된 정보에만 날짜와 출처를 표시하고 모르면 미확인으로 둡니다.
