# 틈길 디자인 시스템 초안

> 2026-10-29 · 시장 탐색과 의견 처리 화면을 위한 초기 설계 제안입니다. 승인된 참고 방향을 MVP에 적용했으며, 실제 선택값과 브라우저 확인 결과는 [구현 기록](design/IMPLEMENTED_SYSTEM.md)에 있습니다. 이 초안의 모든 수치가 구현값인 것은 아니며 사용자 사용성 검사는 별도입니다.

## 디자인이 풀어야 할 문제

틈길은 장보기처럼 가벼운 일상과 통행 불편처럼 신중하게 다뤄야 하는 상황이 한 앱에 있습니다. 탐색 화면은 친근하고 빠르게, 의견 화면은 내용을 확인하고 다음 행동을 선택하기 쉽도록 구성합니다.

- **찾기 쉬운 화면:** 홈과 시장지도에서는 검색과 점포 정보를 먼저 보여 줍니다.
- **판단을 돕는 정보:** 점포의 평소 취급 품목, 출처·확인일, 재고·가격 미확인을 함께 표시합니다.
- **차분한 의견 흐름:** 의견 원문, 정리된 초안, 확인된 결과를 구별합니다.
- **사람을 존중하는 표현:** 시민과 상인 어느 쪽의 책임도 단정하지 않습니다.

화면 행동은 [제품·화면 명세](PRODUCT_SCREENS.md), 상태·공개 범위는 [데이터 계약](DATA_ACCESS.md), 문구는 [UX 문구 기준](UX_COPY.md)에서 관리합니다. 이 문서는 시각 토큰과 구성 패턴을 소유합니다.

## 색상

따뜻한 배경과 차분한 청록색을 조합한 제안입니다. 색상은 레퍼런스 선택과 실제 시안 검토 후 조정할 수 있습니다.

| 역할 | 토큰 | 값 | 사용 예 |
| --- | --- | --- | --- |
| 페이지 배경 | background | #FFFDF8 | 화면 바탕 |
| 카드·입력 배경 | surface | #FFFFFF | 점포 카드, 입력창 |
| 구획 배경 | surface-muted | #F3F0E5 | 보조 정보 묶음 |
| 본문 | text | #1D302C | 제목·본문 |
| 보조 문구 | text-secondary | #52645E | 출처·확인일 |
| 주요 행동 | primary | #126B5B | 주요 버튼과 링크 |
| 주요 버튼 글자 | on-primary | #FFFFFF | 청록 버튼 안의 글자 |
| 선택 배경 | primary-soft | #E5F2ED | 선택한 점포나 필터 |
| 확인 필요 | attention | #8A432A | 주의가 필요한 정보 |
| 오류 문구 | error | #A02F27 | 입력 오류 설명 |
| 입력 경계 | border-control | #697B74 | 흰 배경의 입력 테두리 |
| 키보드 초점 | focus | #126B5B | 초점 테두리 |

초안의 색상 쌍 계산값: 본문/페이지 배경 13.67:1, 보조 문구/페이지 배경 6.18:1, 흰 글자/주요 버튼 6.40:1, 오류 글자/흰 배경 7.17:1. 이 계산은 실제 화면의 모든 색상 조합을 검증한 결과가 아닙니다. 상태는 색 외에 이름과 형태로 구분합니다.

## 글자·간격·형태

| 토큰 | 제안 값 | 사용 |
| --- | --- | --- |
| 화면 제목 | 28px / 줄 높이 36px / 굵기 700 | 화면에서 가장 중요한 제목 |
| 구역 제목 | 20px / 28px / 700 | 검색 결과, 의견 처리 이력 등 |
| 카드 제목 | 18px / 26px / 700 | 점포명, 의견 제목 |
| 본문 | 16px / 24px / 400 | 설명과 입력 |
| 버튼·이름표 | 16px / 24px / 600 | 버튼, 폼 이름표 |
| 보조 문구 | 14px / 20px / 400 | 출처, 날짜, 부가 설명 |
| 간격 | 4·8·12·16·24·32px | 요소 사이 간격. 모바일 좌우 여백 시작값 16px |
| 모서리 | 8·12·16px | 작은 표식 / 버튼·입력·카드 / 큰 패널 |
| 조작 크기 | 최소 44 × 44 CSS px 목표 | 터치 대상. 기본 입력과 버튼 높이는 48px 이상 제안 |
| 초점 표시 | 2px 선, 바깥 간격 2px | 키보드로 선택한 요소 |

한글은 우선 운영체제의 시스템 글꼴과 sans-serif를 사용합니다. 별도 폰트와 아이콘은 라이선스·가독성·성능 확인 후 선택합니다. 글자 확대 시 고정 높이에 잘리지 않도록 구현합니다.

## 공통 컴포넌트

| 컴포넌트 | 구성과 사용 | 반드시 다룰 상태 |
| --- | --- | --- |
| 주요 버튼 | 현재 화면의 대표 행동 1개를 우선 강조 | 기본, 호버, 초점, 눌림, 처리 중, 비활성 |
| 보조 버튼·링크 | 취소·수정·상세 이동. 본문 링크는 색과 밑줄 등으로 구분 | 기본, 초점, 비활성 |
| 입력·검색 | 항상 보이는 이름표, 선택 여부, 필요할 때 도움말 | 기본, 입력, 초점, 오류, 비활성 |
| 점포 카드 | 점포명 → 위치 → 평소 취급 품목 → 출처·확인일 | 기본, 선택, 정보 미확인 |
| 장보기 항목 | 재료명과 체크 상태, 수정·삭제 조작 | 미완료, 완료, 수정 중 |
| 상태 표시 | 상태명과 필요한 설명·시각을 함께 표시 | 접수, 확인, 정보 요청, 협의, 조치 확인, 미해결 |
| 하단 내비게이션 | 아이콘과 이름을 함께 사용 | 현재 탭, 기본, 초점 |
| 안내 메시지 | 상황과 다음 행동을 함께 표시 | 빈 상태, 로딩, 실패, 성공 |

카드 전체 이동과 카드 안의 삭제·체크 조작은 서로 충돌하지 않게 만듭니다. 비활성 이유는 가까이에 설명하고, 오류는 해당 입력에 연결합니다.

## 화면 구성 패턴

| 화면 | 먼저 보이는 것 | 그다음 정보·행동 |
| --- | --- | --- |
| 홈 | 시장 검색과 장보기 이어보기 | 공지와 추가 탐색 |
| 시장지도 | 검색과 점포 목록 또는 가상 도식 | 선택한 점포 상세와 의견 알리기 |
| 장바구니 | 재료 입력과 목록 | 체크·수정·삭제, 관련 점포 |
| 의견 작성 | 위치·상황 입력 | 원문과 초안 비교, 내부 접수와 공식 경로 |
| 처리 이력 | 현재 상태와 확인된 내용 | 시각·사유·후속 확인 계획 |
| 상인·운영자 | 현재 역할과 관련 의견 | 전달 내용, 답변, 확인·결과 기록 |

시민 하단 탭은 홈 · 시장지도 · 장바구니 · 마이 순서입니다. 시장지도는 가상 도식이라면 그 사실을 표시하고 목록으로도 점포를 찾게 합니다.

## 반응형·접근성

| 너비 제안 | 배치 | 확인할 점 |
| --- | --- | --- |
| 320–599px | 단일 열과 하단 내비게이션 | 긴 한글, 지도·목록 전환, 하단 안전 영역 |
| 600–1023px | 여백 확대, 필요 시 목록 2열 | 카드 폭, 입력 길이, 화면 회전 |
| 1024px 이상 | 최대 폭 1200px 제안, 필요 시 목록·상세 병렬 | 본문 줄 길이, 확대 시 재배치 |

구현 후 320px 너비와 글자 200% 확대에서 내용과 조작이 유지되는지 확인합니다. 모든 조작은 키보드로 접근하고 초점이 보여야 합니다. 아이콘 버튼에는 이름을 제공하고, 모션은 사용자의 동작 줄이기 설정을 따릅니다. 로딩·실패·검색 결과 없음·정보 미확인도 별도로 설계합니다.

## 시안 검토 기준과 남은 결정

- [ ] 대파를 찾는 이용자가 검색, 점포 정보, 장바구니를 순서대로 찾을 수 있다.
- [ ] 의견 원문, 초안, 내부 접수 및 공식 신고 경로가 구분된다.
- [ ] 시민·상인·운영자가 같은 의견에서 각자 볼 수 있는 내용과 다음 행동을 이해한다.
- [ ] 상태와 오류를 색상만으로 구분하지 않고, 키보드 초점과 글자 대비를 확인했다.
- [ ] 사진·아이콘·폰트의 출처와 사용 조건을 확인했다.

[화면별 참고와 구성](design/SCREEN_REFERENCES.md), [모션 계약](design/MOTION_SPEC.md)을 함께 적용합니다. 실제 시안의 색상·에셋·배치와 지도 연동은 구현 후 검증해야 합니다. 위 체크리스트는 구현 후 확인할 항목입니다.
